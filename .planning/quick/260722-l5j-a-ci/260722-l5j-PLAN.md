<objective>
Fix the CI Docs gate ordering bug (方案 A). Move the "Docs gate" step to AFTER "Build (tsup)" in both `.github/workflows/ci.yml` and `.github/workflows/publish-npm.yml`.

Purpose: `scripts/check-docs.mjs` executes `dist/cli/index.js --help/--version/version` (lines 366-413). `dist/` is gitignored, so a fresh CI checkout has no `dist/` until the Build step runs. Commit cc8bbad1 added the Docs gate step but placed it BEFORE Build, so every CI run since fails at the Docs gate with "could not run built CLI help". Moving the step to after Build fixes this with zero logic changes.

Output: Two workflow YAML files with reordered steps; check-docs.mjs untouched.
</objective>
