<objective>
Surface the agent's internal feedback (thinking + tool dispatches) to bot chat channels, and stop recoverable mid-turn errors from collapsing the turn into silence.

Two changes that live in the same files:
- Issue #2 (feature): `HeadlessHost.runTurn` drops every kernel event. `runHeadlessTurn` already exposes `onEvent` (turn-driver.ts:54, called at :81) but `host.runTurn` only passes `onAssistantText` + `onError` (host.ts:166-172), so reasoning/tool events are consumed by the eventizer and discarded. Bot chats only ever see the final assistant text. Thread `onEvent` through `host.runTurn`, add a transport-agnostic `SurfaceNotifier`, and wire each channel by its real send model: telegram + weixin push MINIMAL live notices immediately (both are active-capable — telegram by chatId, weixin by userId, neither bounded per inbound message), while qq FOLDS a compact summary into the final reply because its C2C reply is a bounded msgSeq budget that live notices would starve.
- Issue #4 WR-01 (bug): turn-driver.ts:82 flips outcome to "error" for ANY kernel error event, including RECOVERABLE ones. Gate the flip on non-recoverable only — BUT a naive `!recoverable` guard alone REGRESSES the real recoverable path into silence: the only recoverable emitter is force-summary.ts:71-83, which yields error(recoverable:true) then done with NO assistant_final, so outcome stays "end_turn", lastAssistantText stays "", and host.runTurn would return "" (pre-change the user got `t("headless.host.errorFallback")`). Silence violates CLAUDE.md "log + crash > silent wrong output". Fix: keep the `!recoverable` discriminator for terminal classification AND thread the recoverable error's message (onRecoverableError) so host.runTurn surfaces it (scrubbed) whenever the turn ends end_turn with empty assistant text.

Purpose: bot users see live progress (fixes the v1.0 weixin "no internal feedback" UAT gap — weixin now pushes live notices; the gap was a shared HeadlessHost gap affecting all channels); recoverable blips surface a message instead of nuking the turn into silence.
Output: threaded onEvent sink, SurfaceNotifier + tests, per-channel wiring, i18n notice strings in 5 locales, WR-01 regression test.
</objective>
