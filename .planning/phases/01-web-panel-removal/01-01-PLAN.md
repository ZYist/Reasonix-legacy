## Phase Goal

**As a** CLI 用户,**I want to** 在不依赖任何 Web 面板代码的前提下运行 `reasonix chat`/`code`/`run`,**so that** 终端里的 DeepSeek 编程 agent 不再背负面板的耦合与构建负担。

本计划(01-01)交付第一个垂直切片:Web 面板表面(`dashboard/` + `src/server/`)整体切除,所有硬引用(import type 与动态 import)切断,`npm run typecheck` 与 `npm run build` 通过,CLI 可独立构建。注:`src/cli/ui/App.tsx` 的 dashboard 生命周期、picker-broadcast、loop-to-dashboard、cards-to-messages 等面板适配代码**物理依赖**于 `src/server/` 的类型导出,删除 server 必然同步移除这些消费者,故本计划在所难免地完成了 PANEL-03 中所有"会破坏构建"的部分;PANEL-03 的剩余软清理(i18n 死串、运行时冒烟)在 01-02 完成。
