## Phase Goal

**As a** CLI 用户,**I want to** 在没有任何 Tauri 桌面应用与 sidecar 外壳代码的环境下运行 `reasonix qq`/`telegram`/`weixin` 及核心 CLI 命令(`chat`/`code`/`run`/`acp`),**so that** 机器人接入与 CLI 核心不再背负已退役的桌面 GUI 构建负担,且老的 `reasonix desktop` 用户得到清晰的迁移指引而非静默失败。

本计划(03-01)交付本期唯一垂直切片:退役 `reasonix desktop` 子命令(stub + i18n 迁移文案)→ 物理删除 sidecar god module + `src/desktop/` 助手 + `desktop/` Tauri 应用 + 23 个专属测试 → 证明 build/typecheck/lint 三件套退出 0 且三 channel + CLI 核心命令不回归。前置依赖 Phase 2 已满足:QQ/Telegram/微信已解耦到 `src/cli/headless/` HeadlessHost,sidecar 现为孤儿,可安全整删(02-CONTEXT D-09 共存契约本期解除)。
