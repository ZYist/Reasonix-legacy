<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| inbound-message → host | Unauthenticated chat-network text enters `host.runTurn(text)` and drives a full-fs/shell-tool agent loop. The boundary is enforced by the channel's allowlist (qq `decideQQAccess`, tg/weixin parallels) — this plan DOES NOT own that boundary but the host must not bypass it. |
| gate-reply text → pauseGate.resolve | A channel reply string is parsed by `parse*Choice` and turned into a verdict. Spoofed/ambiguous reply text is a Tampering vector. |
| host → DeepSeek API key | The key is loaded once via `loadEndpoint()` and passed to `DeepSeekClient`. Key leakage into logs is an Information Disclosure vector. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | inbound-message → host.runTurn | high | accept | The channel's allowlist (qq `decideQQAccess` in src/qq/access.ts) is the authenticator; the host trusts channel.vetted text. Out of scope to add auth at the host layer — would duplicate channel logic. Accept with rationale: headless host defers all identity claims to the channel module (D-07: access control stays in-channel). |
| T-02-02 | Tampering | gate-bridge consumeReply parse → pauseGate.resolve | medium | mitigate | `parse*Choice` falls through to "deny"/"cancel"/"cancel" on unmatched text — never auto-approves. Verify the default-else branch in consumeReply calls `pauseGate.cancel` or returns the deny choice, never resolve with an allow verdict. Pin in the gate-bridges test (assert unknown text -> deny/cancel). |
| T-02-03 | Information Disclosure | host startup logs / error path | medium | mitigate | errorMeta return path surfaces classification text, never the raw DeepSeek API key. grep host.ts + turn-driver.ts for the literal `ep.apiKey`/`apiKey` symbol printed anywhere other than the DeepSeekClient ctor; assert in test that resolveDir + errorMeta output does not contain the key substring. |
| T-02-04 | Denial of Service | inbound flood → host.runTurn queue | low | accept | The channel module enforces processedMsgIds dedup + PID lock (QQ_LOCK_FILE). The host runs one turn at a time (single aborter); concurrent inbound during a turn is handled at the command layer (02-02 replicates classifyDesktopQQIngress busy/queue). Accept for this plan: the host alone has no queue, the command layer owns it. |
| T-02-SC | Tampering | npm installs | high | mitigate | No new npm install this plan — Pure TS under src/. slopcheck gate not triggered; no [ASSUMED]/[SUS] packages added. |

</threat_model>
