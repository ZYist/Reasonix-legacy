### 安装

```bash
git clone https://github.com/ZYist/reasonix-legacy.git
cd reasonix-legacy
git checkout v1.3.1
npm install
npm run build
npm link
reasonix-legacy --version   # reasonix-legacy 1.3.1
```

从 1.2 迁移见 [`docs/migrating-to-1.3.md`](https://github.com/ZYist/reasonix-legacy/blob/v1.3.1/docs/migrating-to-1.3.md)。

### Remaining deferred（诚实披露）

- **live UAT 未由自动化执行** — 交互式 TTY/Telegram/Weixin/QQ 的真实凭据 UAT（OPS-05）仍是 operator action，未在本 release 自动化中虚构完成；需在真实凭据/网络/终端下人工执行并记录。
- **HeadlessHost channel streaming** — `runTurn` reasoning/tool 事件转发缺口仍是已接受的未来改进，不属本 LTS 发布。
- **Protected core decomposition** — `App.tsx`/`config.ts`/`loop.ts`/大型 tools 拆分留待后续里程碑（characterization tests 保护下）。
